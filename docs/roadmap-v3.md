## 决策点（需要 Wayne 拍板）

1. **A1 覆盖粒度**：第一版只做「用户级覆盖配额与上下文上限」这两个键，还是做完整覆盖框架（所有数值设置都支持渠道/用户覆盖）？——建议先做完整框架但只暴露 2-3 个键，后续逐步放开。
2. **A2 IP 限流默认值**：建议 `60 次/15 分钟/IP`（宽松，防误伤办公室 NAT）。
3. **A4 维护提示文案**：默认「系统维护中，请稍后再试。」是否 OK？
4. **B4 BYOK 网页版**：密钥输入后立即加密入库、永不回显，是否接受这个交互（与聊天指令一致）？
5. **C2 企微失败事件**：需要企业微信后台配置「发送失败事件回调」，需要你提供回调 URL 接入。
6. **E1 告警通道**：邮件（需 SMTP 凭据）还是 Webhook（如 Server 酱/企业微信机器人）？
7. **阶段优先级**：按 A→B→C→D→E 顺序推进，还是你指定优先某一阶段（如 C1 媒体）？
